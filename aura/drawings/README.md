# AURA drawings

Concept drawings, generated by `make_svgs.py` (`python3 make_svgs.py`). Dimensions in mm. **Schematic, not manufacturing drawings.**

| File | Content |
|---|---|
| 01_front_elevation.svg | Front elevation |
| 02_side_elevation.svg | Side elevation |
| 03_top_view.svg | Top view with Z1/Z2 zones |
| 04_exploded_assembly.svg | Exploded layer stack |
| 05_internal_layout.svg | Internal layout (coils, boards, load cells) |
| 06_sensor_placement.svg | Sensor placement with legend |
| 07_power_transmission.svg | Wireless power chain, Z1 and Z2 |
| 08_section_Z2.svg | Layer-stack section through Z2 |

Zone geometry: Z1 Ø70 at x=-125 mm, Z2 220x190 (coil Ø170) at x=+60 mm from body centre.

3D: `../3d/aura_scene.js` (Three.js; click to cycle rotate / exploded / device ghosts).
