## H. Rules for sending
- Personalise the first line. Reference something real you share.
- Don't pitch features in the first message. Ask for an opinion or an intro.
- One follow-up after 3 days, one after 7. Then stop.
- If someone says no, thank them and ask for a referral.
- Never ask a close friend to buy; ask for advice and intros.
- Log every message in `pipeline/tracker.csv`.
